## 用户明确要求

1. 原版过度放大、截断的手机设置页不适合展开内屏；后来把大量设置压进左栏也被用户否定：“UI 太挤了！！！不符合 iPhoneDUO 的实际设计和审美”。
2. 屏幕边缘圆角曾明显呈折线、与边框不贴合；现已按原模型轮廓加密网格。保持此修复，不重新用一个随意半径裁切。
3. 外屏应闭合观看；点击外屏平滑折到 0°，点击内屏展开到 180°；保留手动滑杆和中途反向操作。
4. 用户最新强调：外屏尽量延续原版设置首页的设计思路，头像、账号名和 ID 要看清楚。头像与“野生的装机宅”“@bilibili”是重点，不能为了复制某个系统详情页而藏掉品牌。
5. 不要用大拇指遮挡屏幕，不改现有侧夹手势。折痕 PV 100 µm、中央坡角 1.1° 固定，无需宽度调节功能。

## 当前方案思路与需要讨论的取舍

- 内屏用真实参考的分栏结构和舒展间距，替代缩放手机界面或压缩十九行列表。
- 外屏最新方案优先品牌可见性，显示设置首页，而非先前“与内屏保持同一通用详情”的候选。用户的账号展示要求优先；请讨论如何让这种选择自然、可信，必要时建议更合适的内外屏关系，但不能牺牲顶部账号。
- 保留浅/深色、中性背景和现有图标语言，避免彩色壁纸或新造的宣传卡片。
- 右侧相机与系统轨使用单独安全区；账号卡、列表、文字不得被相机或圆角遮挡。
- 普通手机的原 `ui()` 不在这次重新设计范围。

1. 明确你实际看到了哪几张图；若附件不可读，请直接说明，不假装完成视觉审阅。

3. 提出一个推荐方案及理由，必要时最多一个替代方案。明确内外屏各显示什么、头像/名称/ID 的层级、栏宽、边距、行高和横竖向适配，不堆装饰或额外功能。
4. 区分必须改的问题与可选调整，给出最小实施范围。若现候选有拥挤或不合理之处直接指出。
5. 给出便于主代理/接手 Agent 验收的清单：0°/30° 观看下账号清晰；内屏横纵向；外屏闭合；浅/深色；原普通手机不变；两种渲染模式一致；折叠过程不断帧或跳变。
